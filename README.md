# 🛍️ MEDALU - Tienda Online

Sitio web oficial de **MEDALU**, tienda en línea desarrollada con **Next.js**, **React** y **Tailwind CSS**.

🌐 **Sitio Web Oficial:** [https://www.medalu.online](https://www.medalu.online)

---

## 📌 Categorías de Productos
En **MEDALU** ofrecemos una amplia variedad de productos seleccionados:
* 👗 **Moda Dama:** Ropa elegante, conjuntos y accesorios para dama.
* 🧀 **Lácteos & Alimentos:** Productos lácteos frescos y alimentos de calidad.
* 🍹 **Bebidas:** Variedad de refrescos, jugos y bebidas seleccionadas.
* 🧼 **Limpieza del Hogar:** Artículos y suministros esenciales para el hogar.

---

## 🚀 Despliegue e Infraestructura
* **Alojamiento / Hosting:** Vercel
* **Dominio Personalizado:** `medalu.online`
* **Tecnologías:** Next.js, React, Tailwind CSS
